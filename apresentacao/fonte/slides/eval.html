let rec eval env = function
  | Num n -> n
  | Var x -> (
      match Hashtbl.find_opt env x with
      | Some v -> v
      | None -> raise (Runtime_error ...))
  | Add (a, b) ->
      let x = eval env a in
      let y = eval env b in
      x + y
  (* Mul, Div, Let, Seq e Print: mesma ideia *)

(1:20 · acumulado 6:50) Âncora: a eval recebe uma expressão e calcula o valor; os efeitos acontecem dentro dela. Antes de mostrar as versões, vale explicar a peça central. Todo interpretador tem uma função chamada eval, de evaluate, avaliar. Ela recebe uma expressão e calcula quanto ela vale. À esquerda está o começo dela, na versão imperativa: um caso para cada comando. À direita, ela rodando sobre dois mais n, com n valendo três. A eval recebe uma soma, cai no caso Add e avalia os dois lados. O lado esquerdo cai no caso Num e devolve dois. O lado direito cai no caso Var: lê n na tabela e devolve três. Essa leitura é uma operação de efeito. Por fim, a linha x mais y soma os dois e devolve cinco. Essa divisão vai importar nos resultados: a legibilidade mede o código dentro da eval, e a infraestrutura é o código em volta dela.
