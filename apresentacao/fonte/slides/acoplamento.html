(1:00 · acumulado 12:50) Âncora: nos mecanismos, o efeito novo mexe em código existente. Nas bases, não. Este é o código dessa mudança. À esquerda, os handlers. A eval não muda. O que muda é a composição que instala os handlers, que agora inclui o run_input. Isso acontece nas duas composições, por isso são dois pontos. À direita, as mônadas. O tipo da pilha ganha uma camada de estado para a entrada, e a função run precisa executar essa camada nova. Além disso, para ler da camada nova, o código usa dois lift, que sobem a operação até a camada certa. Nas bases, nenhuma linha existente mudou: entrou só uma função nova de leitura.
