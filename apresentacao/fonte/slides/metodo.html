Comparar tempos entre linguagens mediria também os compiladores. Por isso, cada mecanismo é comparado com uma base simples na própria linguagem, com a mesma estrutura de dados.

razão = 1 + Δ / base

Δ é o custo a mais do mecanismo. Uma base muito barata deixa a razão grande; por isso a comparação entre linguagens é só indicativa.

(1:30 · acumulado 3:20) Âncora: cada mecanismo contra uma base na mesma linguagem; a razão depende da base. O primeiro problema é que cada mecanismo vive numa linguagem diferente. Se eu comparasse os tempos do Haskell com os do OCaml, estaria comparando também os compiladores, e não só os mecanismos. Por isso, eu comparo cada mecanismo com uma versão simples na mesma linguagem, que eu chamo de base. No OCaml, a base é imperativa: uma tabela e exceções normais. No Haskell, a base guarda o estado numa variável mutável, o IORef. Em cada linguagem, o mecanismo e a base usam a mesma estrutura de dados, então a diferença é só o mecanismo. O resultado é uma razão: quanto o mecanismo custa em relação à base. A fórmula mostra um cuidado. A razão é um mais o custo extra dividido pelo custo da base. Se a base for muito barata, a razão fica grande, mesmo com um custo extra pequeno. Por isso eu mostro também os valores absolutos, e a comparação entre as duas linguagens é só indicativa.
