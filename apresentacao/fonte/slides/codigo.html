| Var x -> (

    | Some v -> v

Cada operação direta da base deu lugar a exatamente uma operação de efeito.

(0:50 · acumulado 7:40) Âncora: a estrutura é a mesma; só a operação muda. Este é o mesmo trecho da eval nas duas versões em OCaml: o que lê uma variável. À esquerda, com handlers, o código pede o valor com perform. À direita, a base lê direto da tabela. Se a variável não existe, um pede o erro com perform, e o outro lança a exceção com raise. A estrutura é a mesma, linha por linha. Eu escrevi as versões como espelho uma da outra, para que a diferença medida fosse só o mecanismo. [Passe o cursor pelas linhas em destaque enquanto fala.]
